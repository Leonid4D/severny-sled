# «Северный след» — городские квесты по Архангельску

Авторские пешеходные квесты по историческому центру Архангельска: маршрут, задания, подсказки и проверка
ответов прямо на телефоне. Школьный проект: Гимназия № 3, Архангельск, 2026.

**Сайт:** https://leonid4d.github.io/severny-sled/

## Как играть

1. Откройте сайт на телефоне.
2. Выберите квест и нажмите «Начать квест».
3. Идите по маршруту, на каждой точке ищите ответ на табличке, стенде или постаменте и вводите его.
4. Сайт проверит ответ и покажет часть кода победы.
5. Соберите три части — получите «паспорт победителя», его можно распечатать.

Прогресс сохраняется в браузере: можно закрыть вкладку и вернуться к квесту позже.

## Сейчас на сайте

- **«Город, который воевал»** — готовый маршрут: Монумент Победы (площадь Мира) → памятник Соловецким
  юнгам → памятник участникам Северных конвоев.
- **«От Холмогор к звёздам»** и **«Морская столица Русского Севера»** — в разработке.

## Технологии

Один самодостаточный файл `index.html`: HTML + CSS + JavaScript, без внешних библиотек, шрифтов и картинок.
Сайт работает офлайн; наружу ведут только ссылки в разделе «Источники». Проверка ответов и сохранение
прогресса выполняются в браузере (`localStorage`), сервера нет.

## Как обновить сайт

1. Правите `index.html`. Правильные ответы и части кода — в блоке `ANSWERS` в конце файла.
2. `git add -A`, `git commit -m "правки"`, `git push`.
3. GitHub Pages обновится через 1–2 минуты.
